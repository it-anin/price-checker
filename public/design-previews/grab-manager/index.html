เห็นสถานะทั้งสามไฟล์ในตารางเดียว เปิดแถวที่เปลี่ยนด้านล่าง และส่งออกจากแต่ละแถวไฟล์

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

สรุปจำนวนแถวที่เปลี่ยนบนการ์ดแต่ละสาขา เลือกการ์ดเพื่ออ่านรายละเอียดและส่งออกไฟล์

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

เลือกไฟล์จากแถบด้านซ้าย ตรวจรายการแถวตรงกลาง และอ่านค่าเดิมกับค่าใหม่ในแผงด้านขวา

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

เรียงผลตรวจเป็นไทม์ไลน์ของแต่ละไฟล์ พร้อมคำอธิบายการเปลี่ยนแปลงและปุ่มส่งออกในแต่ละเหตุการณ์

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

เปิดแถวเดียวกันสองฝั่ง ไฮไลต์เฉพาะค่าที่ต่าง เหมาะกับตรวจละเอียดก่อนส่งออกไฟล์ใหม่

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

แยกไฟล์ที่เปลี่ยนกับไฟล์ที่ตรงกัน จัดชุดส่งออกในคอลัมน์ขวาและดูรายละเอียดผ่านแผงด้านล่าง

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

ตารางแถว × คอลัมน์ช่วยเห็นจุดที่ต่างทันที คลิกเซลล์เพื่อดูค่าเดิมและค่าใหม่ในพื้นที่รายละเอียด

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

แสดงข้อมูลใหม่ในตารางพร้อมสีสถานะ ปักแถวที่เลือกไว้กับแถบเทียบค่า และสลับไฟล์จากแท็บด้านล่าง

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

แบ่งงานเป็นเลือกไฟล์ ตรวจการเปลี่ยนแปลง และส่งออก เหมาะกับผู้ใช้ที่ต้องการขั้นตอนชัดเจน

เทียบแถวค่าเดิม / ค่าใหม่Export CSVเปิดเต็มหน้า ↗

วางผลตรวจและชุดไฟล์ที่จะส่งออกคู่กัน เลือกสาขา ดูสรุปการเปลี่ยนแปลง และดาวน์โหลด ZIP หรือ CSV
