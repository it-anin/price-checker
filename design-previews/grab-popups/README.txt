GRAB CSV MANAGER / 10 POST-UPLOAD CHANGE POPUP DESIGNS

Serve this folder with a local HTTP server, e.g. python -m http.server 8080.
Open http://localhost:8080/index.html to compare all ten popup designs.

These are POPUPS that appear over the manager after a changed-file upload.
Each concept has buttons to simulate a changed upload, an unchanged upload,
or a batch of three files. A changed file opens the modal automatically.
An unchanged file shows status text without opening a change popup.
Invalid content shows an inline error. Close/acknowledge and Escape work.
CSV and change-report Export buttons download real files.

All data is fictional. Upload comparisons stay in your browser and do not
fetch or write production data. The live manager uses design 04 / Side Notice.

Concepts opened with ?demo=1 immediately show the post-upload popup state.
